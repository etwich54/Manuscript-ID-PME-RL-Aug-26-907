# Manuscript-ID-PME-RL-Aug-26-907

## Overview
This repository contains the de-identified research data and statistical analysis files supporting the research letter entitled "Early Medicaid Utilization and Reimbursement for Suzetrigine Following FDA Approval in 2025" submitted to Pain Medicine Journal.

## Repository Contents
- Data Files
- R
- Markdown
- File of Outputs

## Statistical Analysis
- R (version 4.5.1; R Core Team, 2025)
- https://www.medicaid.gov/medicaid/national-medicaid-chip-program-information/medicaid-chip-enrollment-data

## Ethics
This study used publicly available, aggregate Medicaid and Children's Health Insurance Program (CHIP) enrollment data obtained from the Centers for Medicare & Medicaid Services (CMS). The analysis did not involve direct interaction with human participants or access to individually identifiable private health information. Accordingly, institutional review board approval and informed consent were not required for this analysis of publicly available, aggregate data.
